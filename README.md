# 📱 Projeto iPhone - DIO - Trilha Java Básico

Este repositório contém a modelagem e implementação Java do componente **iPhone**, desenvolvido como parte do desafio de **POO (Programação Orientada a Objetos)** da **Bradesco - Java Cloud Native | DIO (Digital Innovation One)**.

## 👨‍🏫 Autores

- Gleyson Sampaio (instrutor)
- Desenvolvido por Tayara Cruz

---

## 📌 Descrição do Desafio

O objetivo do desafio é **modelar e diagramar** as funcionalidades do iPhone apresentadas no vídeo de lançamento de 2007, focando em três componentes principais:

- 🎵 **Reprodutor Musical**
- 📞 **Aparelho Telefônico**
- 🌐 **Navegador na Internet**

A partir do diagrama UML criado, também foi realizada a **implementação em Java** das interfaces e da classe principal `Iphone`.

---

## 🧩 Funcionalidades Modeladas

### 🎵 Reprodutor Musical
- `tocar()`
- `pausar()`
- `selecionarMusica(String musica)`

### 📞 Aparelho Telefônico
- `ligar(String numero)`
- `atender()`
- `iniciarCorreioVoz()`

### 🌐 Navegador na Internet
- `exibirPagina(String url)`
- `adicionarNovaAba()`
- `atualizarPagina()`

## 💻 Implementação

As interfaces e a classe `Iphone` foram implementadas em Java. No método `main`, são feitas chamadas para todas as funcionalidades, simulando o comportamento do dispositivo.
